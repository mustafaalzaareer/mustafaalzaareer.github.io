Introduction

in this CTF I played with my team PwnSec and after 48 Hours of competition, we secured second place.

and I managed to solve 3/4 of the DFIR challenges with me temmates so lets start with the writeup.

Zero Hour [Medium]

Description

Our intelligence unit has successfully identified a long-time cybercriminal. According to information provided by our confidential informant, he is preparing something major, and time is critical.
Your mission is to investigate the suspect’s laptop and uncover the following information:
What is the name of the victim?
What is the encryption key?
Flag: 0xL4ugh{name;key}

Solution

We have a disk image of the suspect’s laptop and we want to analyze it, first thing I decided to see the downloads folder to see what is the suspect downloaded, and we got some important things:
he donwloaded discord, outlook and telegram, all these applictions are used for commincations so I thought that we need to analyze them, so I started by analyzing the discord cache and it was empty with nothing intersting, then I moved to outlook artifacts and also nothing intersting so the last option is telegram but there is no artifacts related to it immeditly so after some search in the artifacts I found the first answer in the notifications database.
C:\Users\tarok\AppData\Local\Microsoft\Windows\Notifications\wpndatabase.db

open this database using DB browser and select the Notifications table you can see a notification from telegram and the text is next target is Purdue Pete

now we have the first part lets move to the second one.
while analyzing the disk image I saw that the attacker downloaded WSL from the PowerShell History.
C:\Users\tarok\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadline\ConsoleHost_history.txt

so I decided to analyze the artifacts of wsl, we can find the WSL drive in
C:\Users\tarok\AppData\Local\wsl\{e49649b6-5696-4474-a155-3ed599c71619}

now we need to export the drive and try to analyze it.


now in the home directory we can find file setup.exe upload it to virus total and we can confirm that this file is ransomware, here we can find the encryption key but we need to analyze the malware.

note: in this point I gived the malware to my temmate m7md and he analyzed it and gived me the key.
encryption key: CC2E406C5A9CF1202256672389781D0EBECBF73BBC091B035F88A41B90B7B07F

Flag: 0xL4ugh{Purdue Pete;CC2E406C5A9CF1202256672389781D0EBECBF73BBC091B035F88A41B90B7B07F}

The Hood [Hard]

Description

Teddy MacDonald, a senior CIA operative, is under investigation after classified files leaked from his personal computer. A security camera captured an unidentified individual breaking into Teddy’s residence and tampering with his workstation.
Your mission is to analyze the evidence and uncover the truth—was this a targeted intrusion, or is there more to the story? Using your investigative skills, help the team piece together the events.

Solution

in this challenge the attacker access the computer physically.

(1/17) The intruder connected a device to Teddy’s machine during the breach. Can you uncover its serial number?

ok after the attacker accessed the machine he connected a device(USB) to it and now we need to collect some informations about this device.
first thing is the serial number, we will use the regsitry hive SYTEM for this mission
HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\USBSTOR

here we can se the serial number UM2I126E

(2/17) What is the manufacturer of this device? [company name]

from the device name we can see the company name (just do some search about it)
answer Transcend

(3/17) What is the friendly name that, the intruder assigned to this device?

here we will move to the second hive SOFTWARE
and in the key windows protable devices or MountedDevices we can see the friendly name

answer: OMKALALA

(4/17) After the guy walked in, we need to know how much time he used Teddy’s machine for?

here we need to compine the investigation from multiple artifacts to find the answer, the attacker first connect the device to the machine in 2024-12-10 22:00:21 so he logon to the machine shortly before that, so we need to find the logon time of this LogonID, lets move to the security logs.
first logon to user a1l4m before this was in 2024-12-10 21:59:52 and the Logoff was in 12-10 22:05:45.

Logon:

Logoff:

answer: 2024-12-10 21:59:52_2024-12-10 22:05:45

(5/17) During their brief stay, the attacker appeared to be scouting the system. Which application did they use for reconnaissance?

now we need to the applications that the attacker run it after he access the machine, so lets use prefetch files


the first useful app that run after the logon was taskmgr.exe

(6/17) In the reconnaissance stage the attacker found a vulnerable service on the machine. What is the CVE number assigned to this vulnerability?

the attacker was use the task manager to enemurate the services installed in the system to find any vulnarable service.
This Question take some time from me but i got it in my method, after parse the $MFT and search for the created files after the logon I found one dll created after the logon.

Fortunately we have the dll so we can get the hash and upload it to virustotal

ok we find the malware, lets find the cve that related to this dll and XPS Card Printer, just the first result in google was the cve.

answer: CVE-2024-34329

the cve uses sideloading technique(replace the legitimate dll with a malicious dll in the same path, when the executable run it will load the dll and the maliciouse code will run)

(7/17) What is the SHA1 hash of the file that he used to exploit the service?
it is just the hash of the dll

answer: 7ba477a58eb546b6d3cac3a86633b531ba82fa50

(8/17) What MITRE technique is used by the attacker here?

Dll Side loading -> T1574.002

(9/17) To cover their tracks, the attacker executed multiple commands to disable system logging. What is the name of the file that has these commands?

The first thing that came to my mind at that moment was that the commands should be in a PowerShell script, so I went to the powershell logs.

so we was in the right place.

answer: svc1D3C.ps1

(10/17) To establish persistence, The intruder downloaded additional payloads. What is the IP and Port of the storage C2 server? Format IP:Port

here we need to reverse the dll becouse we dont have logs to store the network connections, i am not good at reverse but this part was easy and I got it by my self.

answer: 3.75.217.26:8080

(11/17) The attacker established a shell connection to a remote server. Your job: pinpoint the exact time the connection started. Format YYYY-MM-DD HH:MM:SS

ok let’s go back to the prefetch files and we need to find when the cmd.exe started.

here we can find the first time when the cmd.exe run after the attacker logon to the machine.

answer: 2024-12-11 04:01:41

(12/17) Which IP address and port were used by the attacker to establish the shell and communicate with the C2 server? Foramt IP:port

This is the most difficult part of the entire CTF (anyone who has participated in this CTF knows what I mean).

here we need to get the shellcode that the dll dropped, again back to me rev teammate, after the team managed to get the shellcode from the dll I just used speakeasy to run the shellcode and it works

(13/17) To ensure control over the system, The attacker runs some commands on the machine. What command did he use to enumerate the machine and ensure access?

back to our friend prefetch files we can see whoami.exe executed after the cmd.exe

answer: whoami

(14/17) Before leaving, the attacker downloaded additional files for exfiltration. Can you uncover the SHA256 hash of the downloaded file? Hint: it’s a zip file

I love prefetch files because tell every thing, after the command whoami we can see that certutil.exe executed so I went to certutil cach and i found a zip file downloaded from the same IP of the C2

http://3.75.217.26/tools.7z

this was in the metadata file
C\Windows\System32\config\systemprofile\AppData\LocalLow\Microsoft\CryptnetUrlCache\MetaData\965B295F92685B983726E076B583D923

we can find the zip file in the file with the same name in the content directory
C\Windows\System32\config\systemprofile\AppData\LocalLow\Microsoft\CryptnetUrlCache\Content

answer: 0905089bb59887880312af06c769cebd967ffa7d2f652fe397ee972ddbed3d25

(15/17) When did the attacker execute the file used for exfiltration last time? Format YYYY-MM-DD HH:MM:SS

if we extracted the zip file we will see file called deep inside.zip and I tried to reverse it to confirm if it used for exfiltration or not.

summery of the malware:
this file was searching for files with extensions .txt or .png in the Desktop and Downloads then comprise them to one file Exfiltrated_data.zip then rename it to Would you lose.png and it used sdelete.exe to remove the files.

so we confirmed the exfiltration, now we need to go back to prefetch files.

answer: 2024-12-11 04:42:35

(16/17) Before exfiltrating the attacker zipped some files for easy exfiltration. What was the final combined file they exfiltrated?

answer: Would you lose.png

(17/17) What treasure trove of files did the attacker manage to steal? Provide a complete list of the exfiltrated files. provide them in alphabetical order. Example (file1.ext-file2.ext- etc..)

Guess what we’re going to do here? Of course, we’re going back to the prefetch files, to see the files that accessed by the malware.

we need the .txt and .png files from the desktop and downloads just.

answer: IMPORTANT.TXT-MEETINGS.TXT-REMINDERS.TXT-RESEARCH.TXT-STAND_PROUD_YOU_ARE_STRONG.PNG-TASKS.TXT-TODOLIST.TXT

and we solved the challenges, thanks for reading and i want to thank the authors for this cool challenges.
