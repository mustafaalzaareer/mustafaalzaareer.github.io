My Analysis

After establishing this foundation, I will use OpenCTI to collect and analyze intelligence related to APT29. The goal is to examine this group’s tactics, techniques, and procedures (TTPs), identify the malware families they have used, and gain deeper insight into their operational patterns.

APT

An Advanced Persistent Threat (APT) is a sophisticated cyberattack in which attackers quietly enter and remain hidden inside a network for an extended period, carefully avoiding detection.

APTs focus on secretly stealing sensitive information, such as intellectual property, financial data, or government secrets.

The attackers typically gain access, establish hidden control, and patiently extract valuable data over weeks, months, or even years.

CTI (Cyber Threat Intelligence)

Cyber threat intelligence (CTI) is the process of collecting, analyzing, and applying data on cyber threats, adversaries, and attack methodologies to enhance an organization’s security posture. It involves taking raw threat data from various sources and transforming it into actionable insights that enable organizations to anticipate, detect, and respond to cyber risks.

OpenCTI

OpenCTI (Open Cyber Threat Intelligence) is an open-source platform designed to aggregate, manage, and visualize cyber threat intelligence in one unified system.

It is designed to:

  • Store information about threats, like malware, campaigns, and IOCs.
  • Analyze the relationships between these threats.
  • Visualize the data, showing connections in an understandable way.
  • Present the information so it’s easy to act upon

  1. Campaigns

In this section, we can review the campaigns associated with the APT29 group. Campaign analysis helps us understand how the group executes operations over time, including the tools, malware, and techniques used in specific intrusions.

  • SolarWinds Compromise

The SolarWinds Compromise was a highly sophisticated supply chain operation attributed to APT29 and publicly disclosed in mid-December 2020. In this campaign, APT29 injected malicious code into the SolarWinds Orion software build process. The trojanized update was then digitally signed and distributed to customers through legitimate software updates, allowing the attackers to gain access to numerous high-profile organizations.

Tools used in this campaign:

  • Mimikatz
  • AdFind

Malware used in this campaign:

This campaign demonstrates APT29’s advanced capabilities in supply chain compromise, stealthy persistence, and large-scale espionage operations.

  • Operation Ghost

Operation Ghost was an APT29 campaign that began in 2013 and targeted ministries of foreign affairs in Europe, as well as the Washington, D.C. embassy of a European Union country. During this operation, APT29 deployed new malware families and leveraged web services, steganography, and dedicated command-and-control (C2) infrastructure tailored to each victim.
(Citation: ESET, The Dukes, October 2019)

Attack Patterns Observed in Operation Ghost
The campaign leveraged several MITRE ATT&CK techniques, including:

  • Initial Access:

    • Valid Accounts (T1078)

  1. Tools

We will now step back to examine the tools most commonly used by the APT29 group and analyze the purpose of each tool within their operations.

Tools Breakdown

  • Tor
    Tor is a software suite and network that provides increased anonymity on the Internet. It creates a multi-hop proxy network and utilizes multilayer encryption to protect both the message and routing information.

  • Tasklist
    The Tasklist utility displays a list of applications and services with their Process IDs (PID) for all tasks running on either a local or a remote computer.

  • Systeminfo
    Systeminfo is a Windows utility that can be used to gather detailed information about a computer.

  • Sliver
    Sliver is an open source, cross-platform, red team command and control framework written in Golang.

  • SDelete
    SDelete is an application that securely deletes data in a way that makes it unrecoverable. It is part of the Microsoft Sysinternals suite of tools.

  • ROADTools
    ROADTools is a framework for enumerating Azure Active Directory environments. The tool is written in Python and publicly available on GitHub.

  • PsExec
    PsExec is a free Microsoft tool that can be used to execute a program on another computer. It is used by IT administrators and attackers.

  • Net
    The Net utility is a component of the Windows operating system. It is used in command-line operations for control of users, groups, services, and network connections.

  • Mimikatz
    Mimikatz is a credential dumper capable of obtaining plaintext Windows account logins and passwords, along with many other features that make it useful for testing the security of networks

  • meek
    meek is an open-source Tor plugin that tunnels Tor traffic through HTTPS connections.

  • ipconfig
    ipconfig is a Windows utility that can be used to find information about a system’s TCP/IP, DNS, DHCP, and adapter configuration.

  • Impacket
    Impacket is an open source collection of modules written in Python for programmatically constructing and manipulating network protocols. Impacket contains several tools for remote service execution, Kerberos manipulation, Windows credential dumping, packet sniffing, and relay attacks.

  • BloodHound
    BloodHound is an Active Directory (AD) reconnaissance tool that can reveal hidden relationships and identify attack paths within an AD environment.

  • AdFind
    AdFind is a free command-line query tool that can be used for gathering information from Active Directory.

  • AADInternals
    AADInternals is a PowerShell-based framework for administering, enumerating, and exploiting Azure Active Directory.
